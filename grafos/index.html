Enunciado formal

Problema 4.3: Transbordos y minutos.

La pregunta en una oración

«¿Qué ruta realiza el menor número de transbordos y qué ruta tarda el menor tiempo en minutos desde Terminal Norte hasta Hospital Universitario, y por qué difieren?»

En los sistemas de transporte masivo, los usuarios se enfrentan a menudo a un dilema cotidiano: ¿conviene tomar una ruta con pocos cambios de tren pero lenta, o hacer transbordos en corredores férreos rápidos?

Este problema modela una red real de 8 estaciones con tres tipologías de transporte con velocidades muy dispares:

  • Línea de Metrocable (Ladera): Conecta puntos lejanos directamente sobre montaña, pero avanza a velocidad baja y con cabinas continuas (17-18 min por tramo).
  • Línea de Metro Troncal (Férrea): Alta velocidad y vía segregada; requiere varias estaciones pero tarda apenas 3 a 4 min por tramo.
  • Red Tranviaria y Alimentadores: Enlaces secundarios transversales (5 a 10 min por tramo).

Definiciones formales del modelo

Vértices \(V\) 8 estaciones (\(A\) a \(H\)).
Aristas \(E\) Tramos directos de transporte intermodal.
Pesos \(w(e)\) Tiempo de viaje en minutos reales (\(w > 0\)).
Transbordo Cambiar de estación o seguir un nuevo tramo (arista).
Objetivo BFS Minimizar número de aristas (menos transbordos).
Objetivo Dijkstra Minimizar la suma ponderada de minutos.

Mecánica algorítmica

BFS (Transbordos) vs. Dijkstra (Minutos).

BFS: Menor número de transbordos

Utiliza una cola FIFO (primero en entrar, primero en salir):

  1. Encola el origen A con distancia 0 tramos.
  2. Saca el frente de la cola y encola los vecinos no visitados.
  3. A cada vecino nuevo le asigna dist[v] = dist[u] + 1.
  4. Ignora los pesos: Asume que cada tramo cuesta 1 salto.
  5. Al llegar a H, garantiza el camino con menor cantidad de aristas.
Resultado en A → H: Elige A → B → H con solo 2 tramos (1 transbordo intermedio). Sin embargo, suma \(18 + 17 = 35\) minutos.

Dijkstra: Menor tiempo de viaje

Utiliza una cola de prioridad / Min-Heap:

  1. Inicializa dist[origen] = 0 y los demás en \(\infty\).
  2. Extrae siempre el nodo con menor tiempo acumulado provisional.
  3. Relaja aristas: Si dist[u] + tiempo < dist[v], actualiza dist[v] y reasigna el predecesor.
  4. Como todos los pesos son positivos, al extraer un nodo su tiempo queda confirmado definitivamente.
Resultado en A → H: Elige A → C → D → E → H con 4 tramos, pero con un tiempo récord de 14 minutos (\(3 + 4 + 3 + 4\)).

    Respuesta formal y contraste

    Las dos rutas frente a frente.

    ¿Por qué no son la misma? Porque BFS busca minimizar el número de aristas (transbordos), asumiendo que todos los tramos tienen el mismo costo (1). Dijkstra, en cambio, evalúa el tiempo real de traslado en minutos.

    Ruta Dijkstra (Óptima en tiempo)

    Tiempo total de viaje: 14 minutos
    Tramos / Transbordos: 4 tramos (3 transbordos)

    Ruta: Terminal Norte → Parque Universidad → Estación Central → Distrito Tecnológico → Hospital Universitario.
    Usa exclusivamente la línea de Metro férreo de alta velocidad (3 + 4 + 3 + 4 = 14 min).

    Ruta BFS (Menor cantidad de transbordos)

    Tiempo total de viaje: 35 minutos (¡21 min más lento!)
    Tramos / Transbordos: 2 tramos (1 transbordo)

    Ruta: Terminal Norte → Cable Mirador → Hospital Universitario.
    Ahorra 2 transbordos pero cae en el tramo de Metrocable de montaña, sumando 18 + 17 = 35 minutos de recorrido lento.

    Implementación en Python (Programación Científica)

    Modelado y algoritmos en Python 3.

    Modelado con lista de adyacencia usando diccionarios, collections.deque para BFS y heapq para Dijkstra: 

    import heapq
from collections import deque

# 1. Definición del grafo: lista de adyacencia con pesos en minutos
grafo = {
    'A': [('B', 18), ('C', 3), ('F', 6)],
    'B': [('A', 18), ('D', 11), ('H', 17)],
    'C': [('A', 3), ('D', 4), ('F', 5)],
    'D': [('B', 11), ('C', 4), ('E', 3), ('G', 5)],
    'E': [('D', 3), ('G', 7), ('H', 4)],
    'F': [('A', 6), ('C', 5), ('G', 8)],
    'G': [('D', 5), ('E', 7), ('F', 8), ('H', 10)],
    'H': [('B', 17), ('E', 4), ('G', 10)]
}

# 2. BFS: Menor número de transbordos / aristas (Cola FIFO, ignora pesos)
def bfs_transbordos(grafo, origen, destino):
    cola = deque([origen])
    visitados = {origen}
    padre = {origen: None}
    while cola:
        u = cola.popleft()
        if u == destino:
            break
        for v, _ in grafo[u]:
            if v not in visitados:
                visitados.add(v)
                padre[v] = u
                cola.append(v)
    # Reconstrucción de la ruta
    ruta, curr = [], destino
    while curr:
        ruta.append(curr); curr = padre.get(curr)
    return ruta[::-1]  # Retorna: ['A', 'B', 'H'] (2 tramos, 35 min)

# 3. Dijkstra: Menor tiempo de viaje en minutos (Cola de prioridad / Min-Heap)
def dijkstra_minutos(grafo, origen, destino):
    pq = [(0, origen)]  # (minutos_acumulados, nodo)
    dist = {nodo: float('inf') for nodo in grafo}; dist[origen] = 0
    padre = {origen: None}
    confirmados = set()
    while pq:
        d, u = heapq.heappop(pq)
        if u in confirmados: continue
        confirmados.add(u)
        if u == destino: break
        for v, peso in grafo[u]:
            if dist[u] + peso < dist[v]:
                dist[v] = dist[u] + peso
                padre[v] = u
                heapq.heappush(pq, (dist[v], v))
    ruta, curr = [], destino
    while curr:
        ruta.append(curr); curr = padre.get(curr)
    return ruta[::-1], dist[destino]  # Retorna: ['A', 'C', 'D', 'E', 'H'], 14 min
